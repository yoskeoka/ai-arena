# 匿名 public match に完了時刻と参加者 provenance を公開する
> **Execution**: Use `/execute-task` to implement this plan. After implementation is complete, use `/review-task` to prepare and create the PR.

Addresses: https://github.com/yoskeoka/ai-arena/issues/362

## 目的と完了境界

Reversi の外部 host viewer が operator resource にアクセスせず、対応可能な completed match を完了順に表示し、
score を提出時点の participant display name と immutable な AI submission/revision ID でラベル付けできるようにする。
`/api/v1-alpha/public/matches`、detail、state の selected public match projection に、selected run の
`completed_at` と generic な `participants[]` を追加する。

`participants[]` の各要素は `player_id`、`display_name`、`ai_submission_id` だけを含む。platform は
Reversi 固有の `black` / `white` fields を追加せず、先手と ruleset からの色への対応付けは visualizer が行う。
表示名と revision ID は selected run の admission 時に pin された player provenance から導出し、現在の bot
プロフィールや private artifact を参照しない。

`completed_at` は selected run が `persisting -> completed` に到達し、terminal artifact を durable に保存した時点で
一度だけ記録する immutable timestamp とする。heartbeat、promotion、ranking、reader failure など後続更新で変化する
`updated_at` は completion timestamp の代用にしない。queued / leased / running / persisting と persistence 前に
`failed` になった run では `completed_at` を省略する。既存 record に backfill は行わず、timestamp がない historical
completed run は public response で `completed_at` を省略する。

完了は、TypeSpec と generated client/OpenAPI、in-memory/Postgres queue、anonymous public projection、および回帰テストが
同じ契約を満たすこととする。private locator、credential、artifact ID / ref、stderr、operator-only read model を公開せず、
Reversi visualizer の変更、list response の platform 側 sorting、private artifact の decode / backfill は対象外とする。

## 仕様変更（black-box）

`docs/specs/platform-public-spectator.md` を先に更新し、次を observable contract として定める。

- 全 public match projection は selected run の participant list を返す。各 participant は player identity、admission 時に
  固定された display name、immutable AI submission/revision identity を持つ。list の順序は submitted player order を維持し、
  game 固有の player role / color は platform が付与しない。
- selected run が durable completion に成功したときのみ `completed_at` を返す。その値は最初の成功した completion transition
  で固定され、promotion や他の record 更新では変わらない。legacy record と未完了 / persistence-failed run では省略する。
- 追加 metadata は public projection に限定し、private artifact locator、credential、bundle / artifact reference、stderr、
  operator record の露出を許さない。alpha API の field-level source of truth は TypeSpec を維持する。

## 実施手順

1. public spectator spec を更新し、generic participant projection と completion-time semantics、omission、non-goals を
   固定する。TypeSpec に `PublicParticipant` と optional RFC 3339 date-time `completed_at` を追加し、public API artifact を
   regenerate する。
2. `QueueRecord` に optional completion time を追加する。in-memory store の transition seam で completion を一度だけ
   record し、clone が pointer alias を持たないことを保証する。worker と recovery / promotion は timestamp を再設定しない。
3. Postgres schema と Atlas migration を追加し、SQL query の create / claim / get / list / update return paths に
   `completed_at` を通す。update は database 内で既存 null の `StateCompleted` transition にだけ `NOW()` を設定し、
   subsequent update は同値を保存する。SQLC を regenerate して Go の load/decode へ接続する。
4. public query projection で selected run の `SubmittedPlayer.PlayerID`、`BotName`、`AISubmissionID` と immutable completion
   time のみを copy し、list/detail/state が一貫した metadata を返すようにする。`BotID`、artifact fields、output path、
   terminal artifact / private read details は response model に追加しない。
5. focused tests を追加する。anonymous GET が participant names/revisions と completed timestamp を返し forbidden fields を
   返さないこと、running response が timestamp を省略すること、completion value が promotion / heartbeat 相当の後続更新で
   変わらないこと、Postgres 再接続後も timestamp/provenance を復元すること、nullable legacy row は安全に omission されることを
   検証する。

## 依存関係と並行性

spec / TypeSpec を先行させる。queue lifecycle persistence と public projection は TypeSpec contract に依存し、schema / SQLC
変更は同一 PR 内で serialize する。generated OpenAPI/client は TypeSpec build 後、generated SQLC は schema/query変更後に更新する。
Reversi viewer はこの ai-arena PR が merge して public contract を release した後に、`participants[]` を player ID order と
ruleset から black / white に対応付けて消費できる。未 merge cross-repository branch を dependency にしない。
